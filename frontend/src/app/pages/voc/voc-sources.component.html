Sources & sync

The automation behind Reveal VoC. LinkedIn's public pages are scraped with a headless browser (no credentials), refreshed on a schedule, and every extraction → analysis → action run is recorded here. No agents are involved in extraction — it is deterministic automation; the agent only reasons over what is stored.
