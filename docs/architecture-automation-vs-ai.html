1. What is automation vs what is an agent

Reveal DQ is not “all AI”. The product is a governed data-quality control plane. Agents inspect and recommend. Automation authenticates, stores, tests connections, runs SQL jobs, and reports. MCP is a protocol used by the agent; it is not a language model.

Automation (deterministic)

Same inputs → same outputs. No LLM. No tool-calling loop.

  • Login / JWT / workspace CRUD / screen ACL
  • Save, edit, approve, activate, retire DQ rules
  • MySQL / Databricks connection test (direct ping)
  • Pipeline run: CALL sp_dq_* + write dq_job_runs
  • Dashboard aggregations from job history
  • Heuristic parsers: SQL / Informatica XML / SSIS DTSX
  • Flow-graph construction from parsed facts
  • Heuristic ETL→Databricks conversion + code validation
  • Conversion check-in to git, Databricks notebook import, job run
  • MCP stdio server (read-only MySQL tools) — protocol, not AI

AI & agents (reasoning)

Claude (Anthropic) plus an orchestrator that chooses tools / fallbacks.

  • DQ Analyser Agent — POST /chat in agents/main.py
  • Intent routing: whole-DB scan vs data Q&A vs “recommend rules”
  • Claude tool loop: list_tables, describe_table, run_select
  • Offline heuristics when ANTHROPIC_API_KEY is empty
  • ETL Analyser follow-up Q&A and node explanations (Claude)
  • Conversion Agent LLM rewrite of Informatica / SQL / SSIS → Databricks SQL or PySpark
  • Model picker: Sonnet 4 / Haiku 3.5 / Opus 4 (Lakebridge is a placeholder engine)
Handoff rule. Agents never write warehouse jobs or mutate dq_rules by themselves. The analyst clicks Save to Rules Engine; the Go API inserts a DRAFT rule and an audit row. Execution is a later, fully automated RunPipeline against MySQL stored procedures.

One-line summary for stakeholders. Reveal DQ uses agents to understand data and legacy ETL and to draft rules or Databricks code. Everything that authenticates, stores, tests, deploys, or runs a DQ job is automation. Claude is optional: without ANTHROPIC_API_KEY the agents degrade to parsers and SQL heuristics.
